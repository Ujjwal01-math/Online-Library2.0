# 📚 Digital Library Management System

A Digital Library Management System built with **Django** that provides a simple and organized platform for managing and accessing digital books. The application allows users to browse books by category, read or download PDFs, and securely manage their accounts. An integrated admin panel enables administrators to add, update, and manage the library collection efficiently.

## ✨ Features

* User Registration & Login
* Secure Authentication System
* Browse Books by Categories
* Read and Download PDF Books
* Admin Dashboard for Book Management
* Upload Book Covers and PDF Files
* Responsive and User-Friendly Interface

## 🛠️ Tech Stack

* Python
* Django
* HTML5
* CSS3
* JavaScript
* SQLite3

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/your-repository.git
   ```

2. Navigate to the project folder:

   ```bash
   cd your-repository
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Apply migrations:

   ```bash
   python manage.py migrate
   ```

5. Run the development server:

   ```bash
   python manage.py runserver
   ```

6. Open your browser and visit:

   ```
   http://127.0.0.1:8000/
   ```
